# niratorn.github.io

repo นี้ทำงานอย่างเดียว คือรับคนที่พิมพ์ที่อยู่เว็บผิดตัวพิมพ์เล็กใหญ่ แล้วพาไปที่อยู่ที่ถูกต้อง

ที่อยู่ของ GitHub Pages แยกตัวพิมพ์เล็กใหญ่ เว็บ OBdating จึงเปิดได้ที่ `https://niratorn.github.io/OBdating/` เท่านั้น เมื่อมี repo นี้ คนที่พิมพ์ `/obdating` หรือ `/OBDATING` หรือสะกดตัวพิมพ์แบบอื่น จะถูกพาไปที่ `/OBdating/` เอง

## ทำงานอย่างไร

- GitHub Pages ส่งไฟล์ `404.html` ของ repo นี้ เมื่อไม่พบที่อยู่ที่เปิดใต้ `niratorn.github.io`
- สคริปต์ท้ายไฟล์ดูส่วนแรกของที่อยู่ ถ้าตรงกับชื่อในรายการ `SITES` โดยต่างกันแค่ตัวพิมพ์เล็กใหญ่ ก็พาไปที่อยู่ที่ถูกต้อง ส่วน `?...` และ `#...` คงไว้ตามเดิม
- ที่อยู่อื่นทั้งหมดขึ้นข้อความ "ไม่พบหน้านี้"
- ที่อยู่ที่สะกดถูกอยู่แล้วไม่ผ่านไฟล์นี้ จึงเปิดเร็วเท่าเดิม

## ข้อควรระวัง

- ห้ามลบหรือเปลี่ยนชื่อ repo นี้ ถ้าลบ ที่อยู่ตัวพิมพ์เล็กและตัวพิมพ์ใหญ่จะกลับไปเปิดไม่ได้
- ทุกไฟล์ใน repo นี้เปิดอ่านได้สาธารณะที่ `https://niratorn.github.io/ชื่อไฟล์` ห้ามใส่ข้อมูลส่วนตัวหรือข้อมูลผู้ป่วย
- repo นี้ไม่มี `index.html` โดยตั้งใจ หน้าแรก `https://niratorn.github.io/` จึงขึ้น "ไม่พบหน้านี้" เหมือนก่อนมี repo นี้
- อย่าเพิ่ม `index.html` หรือ `robots.txt` โดยไม่ถามเจ้าของก่อน สองไฟล์นี้มีผลกับทุกเว็บใต้ `niratorn.github.io` ตัวอย่างเช่น `robots.txt` ที่ห้ามเก็บข้อมูล ทำให้เครื่องมือค้นหาอ่านคำสั่ง `noindex` ในหน้าเว็บไม่ได้
- ไฟล์ `.nojekyll` ต้องอยู่ต่อไป GitHub Pages จะได้ส่งไฟล์ตามที่เป็น

## เพิ่มเว็บอื่น

เปิด `404.html` แล้วเติมชื่อ repo ในรายการ `SITES` ให้สะกดตรงกับชื่อ repo ทุกตัวอักษร

```js
var SITES = ['OBdating', 'AnotherApp'];
```

การทดสอบอ่านรายการนี้เองและตรวจชื่อใหม่ให้ด้วย

## ทดสอบก่อน push ทุกครั้ง

```
node tests/redirect.test.js
python tests/e2e.py
```

- `tests/redirect.test.js` ไม่ต้องติดตั้งอะไรเพิ่ม ตรวจการสะกดทุกแบบของทุกชื่อใน `SITES` และตรวจว่าไม่มีการพาไปซ้ำจนวนไม่รู้จบ
- `tests/e2e.py` ต้องมี `playwright` เปิดเบราว์เซอร์จริงกับตัวจำลอง GitHub Pages ในเครื่อง ใส่ที่อยู่โฟลเดอร์ OBdating ต่อท้ายคำสั่งได้ ถ้าต้องการทดสอบกับแอปจริง

repo นี้ไม่มีขั้นตอน build แก้ `404.html` แล้ว push ได้เลยหลังการทดสอบผ่าน
